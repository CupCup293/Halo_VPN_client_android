# Halo VPN для Android 0.4.0

Версия для телефонов Samsung Galaxy (One UI 2+, Android 10+). Режимы и правила такие же, как в Halo VPN для Windows.

## Что умеет

Экраны один в один по макетам mob-1, mob-2 (тёмная тема) и mob-1-light, mob-2-light (светлая). Шрифты Roboto и JetBrains Mono, флаги стран.

- **Главная.**
  - Кнопка «Вкл/Выкл» и время подключения.
  - Текущий сервер с пингом, скорость загрузки и отдачи.
  - «Быстрый выбор»: три сервера с лучшим пингом.
  - Режим в списке «Правила ▾».
- **Серверы.**
  - Фильтры «Все / Избранные / Европа / Азия» и поиск.
  - «Авто · лучший» без российских узлов.
  - Кнопка «⚡ Пинг».
  - Долгое нажатие на сервер добавляет его в избранные.
- **Доступ.**
  - Карточка подписки: название, остаток трафика, срок.
  - «Продлить» открывает ссылку из подписки.
  - «Обновить», другие подписки, добавление по ссылке или QR-коду.
  - Долгое нажатие удаляет подписку.
- **Ещё (Настройки).**
  - Режим работы: «Обход блокировок», «Кроме РФ», «Весь трафик».
  - Kill Switch (системная настройка Android), «VPN в чужом Wi-Fi», «Без рекламы».
  - Тема.
  - Экран «Приложения» в режимах «Выбранные» и «Кроме них».
  - Пункты для Samsung: «Не усыплять», «Батарея».
- **Уведомление:**
  - сервер и пинг, скорость;
  - кнопки «Отключить» и «Сменить сервер»;
  - флаг страны, видно и на экране блокировки.
- **Плитка в шторке, ссылки `halo://install-config?url=…`.**

Смена режима и «Без рекламы» применяются на лету, без переподключения.

**Ещё → вложенные страницы:**
- **Правила.**
  - Категории обхода: РКН, YouTube, Meta, X, AI, Discord, Telegram, «ушли из РФ», Spotify, торренты.
  - Свои сайты: «через VPN» / «напрямую» / «блок».
  - DNS (DoH) для заблокированных сайтов.
- **Приложения.** Кнопка ⛔ запрещает приложению сеть, пока VPN включён, — файрвол.
  - Ядро спрашивает у Android, чьё соединение (`getConnectionOwnerUid`), и отклоняет его правилом `PROCESS-NAME`.
- **Проверка.** IP напрямую и через VPN с флагом, «открываются ли» 9 сервисов, тест скорости.
- **Соединения.** Что идёт сейчас и по какому правилу; можно закрыть соединение. Журнал ядра.

**Обновления:**
- **Подписки** обновляются в фоне раз в 6/12/24 ч (WorkManager). Подписку можно переименовать: долгое нажатие на неё.
- **Списки блокировок** обновляются раз в 3 дня по Wi-Fi: полный файл runetfreedom урезается прямо при скачивании.
- **«Подключаться при запуске».**

**Диагностика.** Если подписка есть, а серверов нет, экран «Серверы» показывает причину и кнопку «Скопировать отчёт». В отчёте нет адресов подписок.

**Защита от чужих приложений:**
- Если порты 9097/7890 заняты другим VPN-приложением, ядро берёт свободные.
- Если сервис прислал подписку в непонятном формате, Halo повторяет запрос с User-Agent v2rayN.

## Батарея

- **Экран выключен:** служба не опрашивает ядро и не перерисовывает уведомление. Включили экран — продолжает.
- **Уведомление** перерисовывается, только когда в нём что-то поменялось.
- **Пинг** «Авто · лучший» проверяется раз в 5 минут, в «Экономии заряда» — раз в 15. Раньше было раз в 2 минуты.
  - Проверка идёт, только пока группа используется (`lazy`).
- **keep-alive** реже: раз в 30 с, в экономии — раз в 60 с. Радиомодуль дольше спит.
- **Журнал ядра:** в logcat уходят только предупреждения и ошибки, без строки на каждое соединение.
- **Раздел «Батарея» в настройках:**
  - «Экономия заряда» (включена по умолчанию);
  - «Не усыплять Halo VPN» с отметкой ✓, когда готово;
  - переход в «Никогда не усыпляемые» Samsung;
  - «Батарея приложения».

## Как устроено

- `app/` — Kotlin + Jetpack Compose.
  - `HaloVpnService` создаёт туннель и передаёт его дескриптор ядру.
  - Само приложение исключено из туннеля, поэтому ядро выходит в сеть напрямую.
- `core/` — ядро mihomo v1.19.32, собирается в `libhalo.so` и работает внутри процесса приложения.
  - Теги сборки `with_gvisor,cmfa`, выравнивание под страницы 16 КБ.
  - Журнал ядра идёт в logcat с тегом `HaloCore`.
  - Конфиг строит `ConfigBuilder.kt`, правила как в `halo-vpn/electron/config.cjs`.
  - Подписку скачивает приложение: так видны название, остаток и срок у каждой подписки.
  - Если напрямую не вышло, загрузка идёт через ядро.
  - Тело подписки кладётся туда, откуда его читает ядро (`proxy-providers`).
- `app/src/main/assets/geo/` — урезанные гео-базы runetfreedom: 6,4 МБ вместо 90 МБ, только нужные категории.
  - Пересобрать: `node tools/trim-geo.cjs ../halo-vpn/resources/geo app/src/main/assets/geo`.

## Что нужно на компьютере

1. **Android Studio** — в комплекте JDK, Android SDK и эмулятор.
2. **NDK:** Android Studio → Settings → Languages & Frameworks → Android SDK → SDK Tools → «NDK (Side by side)».
3. **Go 1.24+** с https://go.dev/dl/ — только чтобы собрать ядро.
4. Для проверки VPN по-настоящему: **телефон Samsung по USB.**
   - Включить режим разработчика: «Настройки → Сведения о телефоне → Сведения о ПО», 7 раз нажать «Номер сборки».
   - Затем включить «Параметры разработчика → Отладка по USB».
5. По желанию **scrcpy** — экран телефона в окне на компьютере.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File core\build.ps1   # ядро: arm64-v8a и x86_64
```

Затем откройте папку в Android Studio и нажмите Run (телефон или эмулятор).

`gradlew assembleRelease` собирает два APK в `app/build/outputs/apk/release/`:
- `app-arm64-v8a-release.apk` — для телефона;
- `app-x86_64-release.apk` — для эмулятора.

Без ядра приложение тоже собирается: все экраны работают, только подключиться нельзя.

## Чего пока нет (следующие шаги)

- Своего ключа подписи: сейчас release подписан отладочным ключом.
- Автообновления гео-баз: базы обновляются вместе с приложением.
- Экранов правил и соединений.
- «VPN в чужом Wi-Fi» не отличает домашний Wi-Fi от чужого: без доступа к геолокации Android не отдаёт имя сети.
  - VPN включается на любом Wi-Fi.
  - На Android 12+ вместо автозапуска приходит уведомление «Нажмите, чтобы включить».
- Kill Switch включается только в системных настройках VPN.
  - Приложение открывает их и показывает, включён ли он.
